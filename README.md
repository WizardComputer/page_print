# PagePrint

`page_print` is a Ruby gem with a native C extension that renders HTML strings to PDF files using the `plutobook` library.

## Requirements

- Ruby 3.0+
- `plutobook` development headers and library available to the compiler

On macOS with Homebrew:

```sh
brew install plutobook pkg-config
```

If `pkg-config` cannot find `plutobook`, install the gem with explicit include and library paths:

```sh
gem install page_print -- --with-plutobook-include=/path/to/include --with-plutobook-lib=/path/to/lib
```

## Installation

Build and install locally:

```sh
gem build page_print.gemspec
gem install ./page_print-0.1.0.gem
```

## Usage

```ruby
require "page_print"

html = <<~HTML
  <html>
    <body>
      <h1>Hello</h1>
      <p>This PDF was generated by PagePrint.</p>
    </body>
  </html>
HTML

PagePrint.html_to_pdf(html, "output.pdf")
```

## Notes

- The current implementation writes directly to a file path.
- The extension currently keeps a few small debug helpers (`hello`, `echo`, `join_html_and_path`) alongside `html_to_pdf`.
